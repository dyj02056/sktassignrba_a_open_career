## 자기조절력 — 결과를 통제할 수 없을 때 과정을 통제

### 과제 4 — 오늘의 진짜 정보판 (2026-09-15 제출)

- **상황** 외부 API가 늦거나 실패할 때 마지막 정상값을 잃고 현재 상태를 정직하게 못 보여주는 문제.
- **행동** 실패 5종(느린 응답·401/403·호출 제한·오프라인·형식 변경)과 복구 1종 fixture를 미리 합성하고 SHA-256을 매니페스트에 고정.
- **결과** KST 이틀(D1 474건 → D2 94건, +16) 기록, 통과 기준 C01~C28 전부 충족.

### 과제 6 — 플랜두씨 다이어리 (2026-09-16 제출)

- **상황** 계획→실제→돌아보기가 끊기고, 완료 멱등·"0"의 범위·막힘 기준이 모호. Supabase 무료 한도 초과.
- **행동** Q1~Q9 grilling으로 설계 9개 확정, 완료 상태를 Task.completed_at 한 곳으로 일원화, 조건부 UPDATE로 멱등, soft delete, 집계 함수 1개를 3곳에서 재사용.
- **결과** 테스트 24/24 통과, 집계 7개 값 산술 일치, 5 테이블, Vercel 배포.

### 과제 1 — 터미널 포트폴리오 (2026-09-11 제출)

- **상황** 두 해상도(1366×768·1920×1080) 첫 화면에서 소개·활동·근거가 다 보여야 하는데, 실제 점검에서 결함 7개 발견.
- **행동** height → min-height, 폰트·패딩을 clamp()로, 긴 URL 줄바꿈, 제목 단계 승격, 강제 포커스 제거, --muted 상향(7.2:1→8.5:1).
- **결과** 두 해상도 가로 넘침 0건, 대비 8.5:1, 근거 링크 6개, C10~C24 전부 통과.

## 대인관계력 — 듣고 중심을 잡고 연결

### 과제 5 — AI A→B 인수인계 (2026-09-15 제출)

- **상황** AI A가 일부만 구현하고 멈춘 뒤, AI B가 대화 전문 없이 저장소와 인수인계 문서만으로 이어받아야 함. 공통 턴 상한 8턴.
- **행동** 검사 10개를 사전 고정하고, AI A의 자발적 HANDOVER.md(7항목 중 3개 충족)를 7항목 형식으로 재구성, 섹션 3을 "고정 검사 10개 및 결과"로 확장.
- **결과** AI A 19분(1턴) → AI B 11분(5턴), 총 30분에 검사 10/10 통과.

### 과제 8 — 패스키 인증 (2026-09-21 제출)

- **상황** 1번 포트폴리오를 보존한 채 그 위에 패스키로 잠긴 비공개 영역을 얹어야 함. 비밀번호 없이 공개키만 서버 저장.
- **행동** main 보존 + assignment8 분기, ?userId=·body·X-User-Id 무시하고 세션 userId로만 조회, challenge는 검증 직전 즉시 삭제(TTL 5분), 소유권 확인, 세션 토큰 앞 6자만 응답.
- **결과** 인증 4흐름·KV 6종·검증 4종 전부 통과, 남의 자료 접근 전부 차단, 마지막 패스키 분실 시 복구 불가 한계 명시(C51).
